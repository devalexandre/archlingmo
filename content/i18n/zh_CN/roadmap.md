## 路线图

这里是我们接下来要做的事情。已经完成的内容请查看[功能](#recursos)。
日期仅为预估，可能会有变动。建议和优先级在我们的
Discord 上讨论，每一项都会成为 GitHub 上公开的 pull request。

优先级来自论坛和其他发行版评测中最常被提到的问题：
担心更新会搞坏系统、驱动问题、不用终端就能安装软件，
以及无需专业知识也能维护电脑。

### 28/09 至 08/11 · 轻松装软件

- [ ] **应用商店**：Flathub 和 Arch 软件仓库集中在一处，附带评分和截图；AUR 软件包仅在提示后提供
- [ ] **打开 Windows 程序**：点击 .exe 文件时，推荐 Linux 替代软件，或使用 Bottles/Wine 运行
- [ ] **一键畅玩游戏**：Steam、Proton 和游戏模式，并提醒哪些带反作弊的游戏无法在 Linux 上运行

### 09/11 至 13/12 · 电脑维护

- [ ] **系统监视器** (Ctrl + Shift + Esc)：处理器、内存、磁盘、网络和显卡，应用和进程列表，以及“结束”按钮
- [ ] **清理**：缓存、回收站、无人使用的软件包、更新缓存和未使用的 Flatpak 运行时，确认前显示可释放的空间
- [ ] **磁盘地图**：查看是什么占用了空间，以及被遗忘的大文件
- [ ] **系统信息**，附带“复制报告”按钮，方便在 Discord 或论坛上求助
- [ ] 摄像头背景虚化和替换，抠图精细（头发、耳机和肩膀）

### 14/12 至 31/01/2027 · 放心更新

- [ ] 每次更新前**自动创建还原点** (btrfs)，可直接从启动菜单回滚
- [ ] 在设置和更新程序中提供**“回到昨天”**按钮
- [ ] 更新程序用通俗易懂的语言显示 Arch 新闻，并暂缓需要手动处理的更新
- [ ] **驱动管理器**：检测显卡 (NVIDIA、AMD、Intel) 并安装合适的驱动，随内核保持更新

### 01/02 至 31/03/2027 · 日常硬件

- [ ] **打印机和扫描仪**自动识别，添加界面简单明了
- [ ] **蓝牙耳机**：在音乐音质和麦克风之间选择，通话结束后恢复音乐音质
- [ ] **电池**：将充电上限设为 80% 以延长寿命，电源配置文件和电池健康状况
- [ ] 所有应用清晰的分数缩放 (125%、150%)，可按显示器单独设置

### 01/04 至 31/05/2027 · 集成与外观

- [ ] 一键**切换布局**：macOS 风格、Windows 风格或 Lingmo
- [ ] 在文件管理器中查看文件的**历史版本**，就像 Time Machine 一样
- [ ] **手机互联**：与 Android 和 iPhone 同步通知、文件和剪贴板 (KDE Connect)
- [ ] **云账户**：Google Drive 和 OneDrive 直接显示在文件管理器中
- [ ] 从截图中复制文字 (OCR)
- [ ] 安装程序在与 Windows 并存安装时提示 BitLocker 和 Secure Boot 相关事项

### 2027 年 6 月起

- [ ] 可选且注重隐私的 AI 助手（本地模型）：总结、翻译和解释所选文本
- [ ] 家长控制：使用时长和就寝时间
- [ ] Wayland 会话
- [ ] 每个版本自动构建并测试 ISO
- [ ] 为有需要的用户提供集成 Windows (WinBoat) 的 Office 和 Adobe
