## 简介

**ArchLingmo** 是 [Lingmo OS](https://lingmo.org) 面向 Arch Linux 的社区版本，
整个桌面已迁移到 **Qt 6**，相关改动也会陆续提交给官方项目。

- **精致外观**：重新设计的顶栏、程序坞、Spotlight、控件和窗口按钮，支持浅色和深色主题。
- **紧跟最新**：Qt 6、KDE Frameworks 6 和 KWin 6，直接来自 Arch 官方软件仓库。
- **方便实用**：Super 键快捷键，设置中的快捷键和开机启动页面，托盘里是常用的应用。
- **开放透明**：所有代码都在 GitHub 上，每一项改进都会作为 pull request 提交给 Lingmo。
