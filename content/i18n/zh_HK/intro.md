## 關於

**ArchLingmo** 是 [Lingmo OS](https://lingmo.org) 為 Arch Linux 而設的社群版本，
整個桌面已移植至 **Qt 6**，而所有修改亦會同步提交給官方項目。

- **用心設計**：重新設計的頂部列、Dock、Spotlight、控制項及視窗按鈕，提供淺色和深色主題。
- **緊貼最新**：Qt 6、KDE Frameworks 6 及 KWin 6，直接來自 Arch 軟件庫。
- **方便實用**：以 Super 鍵操作的快捷鍵、「設定」內的快捷鍵及開機啟動頁面，還有放着常用程式的系統匣。
- **開放**：所有程式碼都在 GitHub 上，每項改進都會以 pull request 回饋給 Lingmo。
