## Дорожня карта

Що ми ще збудуємо. Те, що вже готово, описано в розділі [Можливості](#recursos).
Дати орієнтовні й можуть змінитися. Пропозиції та пріоритети обговорюємо в нашому
Discord, а кожен пункт стає відкритим pull request на GitHub.

Пріоритети визначає те, що найчастіше згадують на форумах і в оглядах інших дистрибутивів:
страх, що оновлення зламає систему, драйвери, встановлення програм без термінала та
догляд за комп’ютером без технічних знань.

### 28/09 – 08/11 · Програми без клопоту

- [ ] **Магазин застосунків**: Flathub і репозиторії Arch в одному місці, з оцінками та знімками; пакунки з AUR лише з попередженням
- [ ] **Відкриття програм для Windows**: після клацання на .exe пропонує альтернативу для Linux або запускає через Bottles/Wine
- [ ] **Ігри в один клік**: Steam, Proton та ігровий режим, з попередженням про ігри, чий античит не працює в Linux

### 09/11 – 13/12 · Догляд за комп’ютером

- [ ] **Системний монітор** (Ctrl + Shift + Esc): процесор, пам’ять, диск, мережа та відеокарта, список застосунків і процесів та кнопка «Завершити»
- [ ] **Очищення**: кеші, смітник, непотрібні пакунки, кеш оновлень і невикористані середовища Flatpak, з показом звільненого місця перед підтвердженням
- [ ] **Мапа диска**: що займає місце та забуті великі файли
- [ ] **Відомості про систему** з кнопкою «Скопіювати звіт», щоб попросити допомоги в Discord або на форумах
- [ ] Розмиття та фон камери з якісним вирізанням (волосся, навушники й плечі)

### 14/12 – 31/01/2027 · Оновлення без страху

- [ ] **Автоматична точка відновлення** перед кожним оновленням (btrfs), з можливістю повернутися просто з меню завантаження
- [ ] Кнопка **«Повернутися до вчора»** у Налаштуваннях і в програмі оновлення
- [ ] Програма оновлення показує новини Arch простою мовою та затримує оновлення, які потребують ручного втручання
- [ ] **Менеджер драйверів**: визначає відеокарту (NVIDIA, AMD, Intel), встановлює потрібний драйвер і підтримує його відповідно до ядра

### 01/02 – 31/03/2027 · Повсякденне обладнання

- [ ] **Принтери та сканери** розпізнаються самі, з простим екраном для додавання
- [ ] **Bluetooth-навушники**: вибір між якістю музики та мікрофоном, з поверненням до якості після дзвінків
- [ ] **Акумулятор**: обмеження заряду до 80% для довшої служби, профілі живлення та стан акумулятора
- [ ] Чітке дробове масштабування (125%, 150%) в усіх застосунках, для кожного монітора

### 01/04 – 31/05/2027 · Інтеграція та вигляд

- [ ] **Зміна компонування** в один клік: стиль macOS, стиль Windows або Lingmo
- [ ] **Попередні версії** файлів у файловому менеджері, як у Time Machine
- [ ] **Інтегрований телефон**: сповіщення, файли та буфер обміну з Android та iPhone (KDE Connect)
- [ ] **Хмарні облікові записи**: Google Drive та OneDrive у файловому менеджері
- [ ] Копіювання тексту зі знімка екрана (OCR)
- [ ] Інсталятор, що попереджає про BitLocker і Secure Boot під час встановлення поруч із Windows
