## ロードマップ

これから作っていくもの。すでに完成しているものは[機能](#recursos)をご覧ください。
日程は予定であり、変更される場合があります。提案や優先順位は私たちの
Discord で話し合われ、各項目は GitHub 上の公開 pull request になります。

優先順位は、フォーラムや他のディストリビューションのレビューで特によく挙がる声をもとに決めています。
アップデートでシステムが壊れる不安、ドライバー、ターミナルを使わないソフトのインストール、
そして専門知識なしでパソコンを手入れできることです。

### 28/09〜08/11 · 手間いらずのアプリ

- [ ] **アプリストア**: Flathub と Arch のリポジトリをひとつの場所に、評価とスクリーンショット付きで。AUR のパッケージは警告付きでのみ
- [ ] **Windows ソフトを開く**: .exe をクリックすると、Linux 向けの代替ソフトを提案するか、Bottles/Wine で実行
- [ ] **ワンクリックでゲーム**: Steam、Proton、ゲームモード。Linux で動作しないアンチチート搭載ゲームには警告を表示

### 09/11〜13/12 · パソコンの手入れ

- [ ] **システムモニター** (Ctrl + Shift + Esc): プロセッサー、メモリー、ディスク、ネットワーク、グラフィックカード、アプリとプロセスの一覧、「終了」ボタン
- [ ] **クリーンアップ**: キャッシュ、ゴミ箱、使われていないパッケージ、アップデートのキャッシュ、未使用の Flatpak ランタイム。確定前に空く容量を表示
- [ ] **ディスクマップ**: 何が容量を使っているか、忘れられた大きなファイル
- [ ] **システム情報**と「レポートをコピー」ボタンで、Discord やフォーラムで手軽に助けを求められる
- [ ] 高品質な切り抜き (髪、ヘッドホン、肩) によるカメラの背景ぼかしと背景変更

### 14/12〜31/01/2027 · 安心してアップデート

- [ ] アップデートのたびに**自動で復元ポイント**を作成 (btrfs)。起動メニューから直接元に戻すことも可能
- [ ] 設定とアップデーターに**「昨日の状態に戻す」**ボタン
- [ ] アップデーターが Arch のニュースをわかりやすい言葉で表示し、手動での対応が必要なアップデートを保留
- [ ] **ドライバーマネージャー**: グラフィックカード (NVIDIA、AMD、Intel) を検出して適切なドライバーをインストールし、カーネルに合わせて最新に保つ

### 01/02〜31/03/2027 · 毎日使うハードウェア

- [ ] **バッテリー**: 長持ちさせるための 80% 充電制限、電源プロファイル、バッテリーの状態
