## Sobre

O **ArchLingmo** é uma versão comunitária do [Lingmo OS](https://lingmo.org) para o Arch Linux,
com o desktop inteiro migrado para **Qt 6** enquanto as mudanças são enviadas ao projeto oficial.

- **Visual cuidado**: barra superior, dock, Spotlight, controles e botões de janela redesenhados, em tema claro e escuro.
- **Atual**: Qt 6, KDE Frameworks 6 e KWin 6, direto dos repositórios do Arch.
- **Prático**: atalhos com a tecla Super, página de atalhos e de inicialização nas Configurações, bandeja com os apps de sempre.
- **Aberto**: todo o código está no GitHub, e cada melhoria vira um pull request para o Lingmo.
